# Prompts

Curated, **tested** AI prompts for report tasks. Each prompt should include:

- Goal
- Inputs it expects
- Model family tested on (e.g. `gpt`, `claude`, `gemini`)
- When it works well
- Where it fails / known limitations
- A short example output

Naming: `<task>.<model>.md`, e.g. `test-summary-draft.gpt.md`.
