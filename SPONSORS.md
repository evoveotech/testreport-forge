# Sponsors

Evoveo Smart Reporter is a free, open-source test reporting platform —
AI-powered failure analysis, flakiness detection, quality gates, and a
multi-tenant leadership dashboard. Every feature is included, no paywalls,
no license keys.

**Building and maintaining this takes real time and money.** If this tool
saves your team hours every sprint, consider sponsoring its continued
development.

## How to Sponsor

### GitHub Sponsors

[![Sponsor on GitHub](https://img.shields.io/badge/Sponsor-on%20GitHub-ea4aaa?logo=github-sponsors&logoColor=white)](https://github.com/sponsors/evoveotech)

Recurring monthly sponsorships via GitHub. Ideal for teams and companies
that want to support the project long-term.

### Buy Me a Coffee

[![Buy Me a Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-ffdd00?logo=buy-me-a-coffee&logoColor=black)](https://buymeacoffee.com/ipoboards)

One-time donations. Quick and easy — no account needed.

## What Sponsorship Funds

- **Maintenance** — bug fixes, dependency updates, CI infrastructure
- **New features** — community-requested features voted on by sponsors
- **Cloud costs** — demo deployments, screenshot generation, test runners
- **Documentation** — user guides, video tutorials, example projects

## Sponsor Tiers (suggested)

| Tier | Monthly | What you get |
|------|---------|--------------|
| **Supporter** | $10 | Name in SPONSORS.md, priority issue triage |
| **Team** | $50 | Above + logo in README, feature request voting |
| **Enterprise** | $200 | Above + dedicated support channel, roadmap input |
