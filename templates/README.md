# Templates

Reusable report templates, organized by **audience** and tagged by **locale**.

Naming: `<report-type>.<lang>.md`, e.g. `regression-summary.en.md`.

Suggested starter templates:

- `bug-report.en.md`
- `regression-summary.en.md`
- `release-sign-off.en.md`
- `exploratory-session-chart.en.md`
- `test-plan-status.en.md`
- `executive-risk-brief.en.md`
